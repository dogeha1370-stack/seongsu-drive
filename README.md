# 성수 드라이브

성수동을 모티브로 만든 3D 생활·운전 샌드박스 게임입니다. 현금 0원과 반지하에서 시작해 배달과 아르바이트로 돈을 벌고, 차량을 타고 동네를 탐험합니다. 월세는 300,000원, 첫 납부까지 7일입니다.

## 플레이

- WASD / 방향키: 이동, Shift: 달리기, Space: 점프 / 차량 브레이크
- 모바일: 왼쪽 원형 조이스틱 드래그로 이동, 오른쪽 화면 드래그로 시점 회전
- E: 배달 픽업·완료, 가까운 차량 상호작용. 운전자가 있으면 먼저 끌어내고 다시 누르면 탑승
- V: 바이크 승하차. 쓰러진 배달기사의 바이크도 가져갈 수 있습니다.
- Q: 권총 장착, 좌클릭 / F: 주먹 공격 또는 발사, R: 재장전
- 권총을 든 채 우클릭 유지: 어깨 너머 조준. 짧은 우클릭: 1인칭 조준 전환. 조준 중 좌클릭으로 발사
- P: 휴대폰, I: 가방, M: 지도, Esc: 창 닫기 / 일시정지

집에서는 현관을 걸어 나가면 외출합니다. 장소의 원에 들어가면 방문 창이 자동으로 열립니다. 창을 닫거나 원 밖으로 걸어 나가면 닫히며, 닫은 창은 원을 나갔다 다시 들어와야 자동으로 열립니다.

원형 미니맵은 바라보는 방향에 맞춰 회전하며 플레이어 화살표는 위를 가리킵니다. 전체 지도는 북쪽이 위이고, 장소마다 아이콘과 현재 위치 기준 거리가 표시됩니다. 계기판은 탈것에 탑승했을 때만 표시됩니다.

## 생활과 동네

- 배달 6개 동선과 첫 배달 정착 보너스, 편의점 아르바이트, BBQ 치킨집 주방 일과 배달
- 맥도날드와 BBQ 건물·간판, 각각 6개 메뉴. 음식은 HP를 회복하며 메뉴 가격은 게임 경제용 설정입니다.
- 피로·포만감 수치와 페널티 제거. 오래된 저장 데이터의 해당 필드도 정리합니다.
- 가방 12칸, 집 보관함, 주택 5단계와 보증금 차액 정산, 4×4 부동산 매물 슬롯
- 반지하 가구 5종 구매·배치·보관, 벽지와 바닥 색상 변경, 가구별 3곳 배치 위치
- NPC 사망 시 현금이 한 번 떨어지고 가까이 가면 획득. 차량·바이크 충돌, 교통사고 피해, 캐릭터 위 데미지 숫자
- 야간 가로등과 실내외 조명, 도로·횡단보도 위 나무 제외, 일반 차량의 주행과 정체 회복
- 월세·생활비, NPC 의뢰, 경찰 신고·수배·체포, 탄약·재장전, 동네 이벤트
- 돈·생활 상태·가구·연락처·위치는 현재 브라우저에 자동 저장

성인 여성 NPC 6명에게 가까이 가면 번호 요청 버튼이 나타납니다. 요청에는 3초가 걸리며, 성공률은 `15% + 70% × 현금 / (현금 + 500,000)`입니다. 0원은 15%, 50만 원은 50%, 100만 원은 약 61.7%이며 최대 85%에 가까워집니다. 돈은 차감하지 않습니다. 성공하면 연락처가 저장되고 NPC가 플레이어 옆을 따라옵니다. 동행을 끝내거나 다시 만났을 때 재개할 수 있습니다. 거절 후에는 게임 시간 10분을 기다립니다.

## 친구와 접속

상단 **함께하기**에서 이름을 쓰거나 자동 이름으로 공개 거리에 접속합니다. **친구 방 만들기**로 생성한 8자리 코드를 공유하면 같은 방에서 만날 수 있습니다. 한 방에 최대 24명이 입장하며 이름·위치·방향·탑승 상태·짧은 인사를 공유합니다. 집 내부, NPC와 교통, 전투, 돈과 소지품은 각자의 게임에 유지됩니다. 공유 전투나 공동 경제는 구현하지 않았습니다.

개발 서버는 같은 네트워크의 다른 기기에서도 접속할 수 있도록 설정되어 있습니다. 서버를 실행한 컴퓨터의 로컬 IP 주소에 `:3000`을 붙여 접속한 뒤 같은 방 코드를 입력하세요. localhost는 해당 컴퓨터에서만 유효합니다. 실제 다른 기기의 접속은 네트워크와 방화벽 설정에 달려 있습니다. 서로 다른 네트워크에서 플레이하려면 모두 접근할 수 있는 서버에 게시해야 합니다.

게스트 API는 Cloudflare D1을 사용합니다. 개발 서버에서는 프로젝트 안의 로컬 D1을 사용하고, 게시 환경에서는 `.openai/hosting.json`의 `DB` 바인딩이 필요합니다. 서버가 최초 요청에 필요한 스키마를 만듭니다. 접속 토큰, 방 격리, 만료, 재접속, 입력 범위를 서버에서 검증합니다.

## 개발과 검증

Node.js 22.13 이상에서 `npm install`, `npm run dev`로 시작합니다. `npm run build`는 Cloudflare Workers용 빌드를 생성합니다.

- `npx tsc --noEmit`: 타입 검사
- `node life-check.mjs`: 경제, 저장, 현금 획득, 바이크 교환, 가구, 음식과 BBQ 수익
- `node world-rules-check.mjs`: 충돌, 도로 배치, 조이스틱과 현금별 요청 확률
- `node game-smoke-check.mjs`: 실제 Three.js 장면과 게임 상태의 통합 검사. DOM·GPU 표면만 대체하므로 브라우저 렌더링 검증을 대신하지 않습니다.
- `node presence-check.mjs`: 실행 중인 개발 서버에서 게스트 두 명의 이동, 방 격리, 자동 이름, 실내 숨김, 만료·재접속 검증
- 기존 물리·보행자·전투·리스폰·캐릭터 검사: `physics-check.mjs`, `pedestrians-check.mjs`, `combat-check.mjs`, `respawn-check.mjs`, `human-check.mjs`

맵은 가상 성수 구역이며 실제 지형이나 상점의 정밀 복제는 아닙니다. 이미지 출처와 구현 참고 자료는 [ASSETS.md](ASSETS.md)에 기록했습니다.
